Capabilities

Four systems, one point of view.

Each one watches a different surface. Together, they give you a single, coherent read on what's actually happening across your stack — not four separate dashboards to reconcile at 2am.

Predictive threat detection

Machine learning models trained on historical attack data and live network traffic patterns spot anomalies before they escalate into a breach — not after.

Automated incident response

An AI agent triages and summarizes alerts as they arrive, so your SOC spends its attention on the handful that matter instead of drowning in the queue.

Code & vulnerability scanning

Context-aware models read source code the way a senior engineer would — finding real vulnerabilities and ranking patches by actual risk, not just pattern match.

Phishing detection

NLP models trace suspicious language, sender behavior, and domain patterns to catch phishing attempts that slide past legacy filters.

One system, not a bolt-on

Built with the response in mind, not added to it after.

Most security tools are built first, then wired up to whatever team ends up running them. Redoubt was designed the other way around — the detection engine and the response workflow were built as one thing from day one, so nothing gets lost translating an alert into an action.

Detection and response share context

When the model flags something, it hands off everything it already knows — no re-explaining the situation to a separate tool or a separate team.

Humans stay in the loop, not out of it

Low-risk findings resolve automatically. Everything else reaches a person with the reasoning already attached — not just a score.

How it works

From raw signal to resolved incident.

One pipeline, four stages. Every alert you see has already been through this before it reaches a human.

01

Ingest

Network traffic, logs, source code, and inbound email are streamed in continuously, no agents to babysit.

02

Analyze

Models trained on historical attack patterns compare live behavior against what "normal" looks like for your environment.

03

Detect

Deviations are scored, ranked, and summarized in plain language — with the reasoning attached, not a black-box score.

04

Respond

Low-risk items are handled automatically. Everything else lands in front of your team, already triaged.

Agent traceability Every action Redoubt's agent takes — a query, a triage decision, a drafted report — is logged as a replayable step, not a black-box output. Full observability into what your AI actually did, end to end.
Self-hosted core The detection engine and chat runtime are open source and deployable entirely on your own infrastructure. Complete data sovereignty — nothing leaves your network unless you choose it to.
MCP-compatible connectors Built on the open Model Context Protocol standard used across the current generation of AI assistants. One integration layer, compatible with the same connector ecosystem as other major AI platforms.
Community detection rules Threat and phishing detection patterns are published, versioned, and reviewed in the open, like a package registry. Benefit from a shared pattern library instead of starting from zero.
Role-based access & audit trail Fine-grained permissions per environment, plus an immutable log of every query and action taken. Meet internal compliance requirements without bolting on separate tooling.
Offline / air-gapped mode Run detection and chat models fully disconnected from the internet, for classified or restricted environments. Works even where cloud connectivity isn't an option.
Managed cloud tier An optional hosted version with support and uptime SLAs, for teams that don't want to run their own infrastructure. An enterprise on-ramp, without needing an ops team on day one.
